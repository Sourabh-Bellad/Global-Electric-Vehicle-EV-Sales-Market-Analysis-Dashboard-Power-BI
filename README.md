# 🌍 Global Electric Vehicle (EV) Analytics Dashboard | Power BI

## 📌 Project Overview

An interactive Power BI dashboard developed to analyse global Electric Vehicle (EV) sales, stock, market share and adoption trends across different regions, years, vehicle modes and powertrain categories.

The project transforms EV data into meaningful business insights through interactive visualisations, DAX calculations and dynamic reporting.

## 🎯 Project Objectives

- Analyse global EV sales and stock trends.
- Track EV market share and adoption patterns.
- Compare EV performance across regions and powertrain categories.
- Understand Year-over-Year (YoY) growth and trends.
- Evaluate EV sales under different scenarios.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Data Modelling
- Time Intelligence
- Interactive Data Visualization

## 📊 Dashboard Pages & Features

### 1. Global EV Overview
- Total EV Sales and Total EV Stock KPIs.
- EV Market Share analysis.
- Year-over-Year (YoY) Sales Growth.
- Regional performance analysis.
- EV Sales by Powertrain.
- Interactive geographical map.

### 2. EV Type Insights
- EV performance by vehicle mode.
- EV Market Share by Mode.
- Sales comparison across vehicle categories.
- Year-wise trend analysis.

### 3. Scenario Analysis
- EV Sales analysis by scenario.
- Scenario-based comparisons.
- Interactive filters for Year, Region and Powertrain.

### 4. Tabular Matrix Reporting
- Year-wise EV Sales and Stock reporting.
- Region-wise performance comparison.
- Powertrain-based analysis.
- Interactive Matrix visual with filtering capabilities.

## 📈 Technical Highlights

- Created custom DAX measures for EV Sales, EV Stock and Market Share.
- Implemented YoY growth calculations and trend indicators.
- Used KPI Cards for executive-level reporting.
- Designed interactive slicers and synchronized filters.
- Developed Matrix and tabular reporting for detailed analysis.
- Applied a consistent executive-style dashboard theme.
